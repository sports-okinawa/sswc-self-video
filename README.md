# sswc-self-video

SSWC(パワーラボ浦添・糸満パーク)の 90 秒の自撮りジム動画を、自動で編集するツールです。

- 撮影した縦動画を、台本に合わせて無音や言い直しを詰め、字幕・強調・数字の大写し・締めのカードを付けて 1080x1920 の mp4 にします。
- 編集は Remotion + whisper.cpp + ffmpeg で、GitHub Actions 上で動きます。
- SSWC のコーチ画面の「動画を編集」ボタンから起動します。ジョブの中身(台本など)は実行時にアプリから取得するため、台本・文字起こし・ファイル名・秘密はこのリポジトリにもログにも出しません。
- BGM・効果音はこのリポジトリに含めません(実行時にドライブから取得します)。

## ローカルでの使い方

準備中です(`scripts/edit.mjs` を追加したあとに書きます)。

```
npm install
npm test
```
