# SSWC 自撮り動画の自動編集: 設定手順書

スタッフが自分で撮った動画を、アプリの「論文ストック」画面のボタン一つで自動編集するための、最初の一回だけの設定です。
PC のブラウザとスマホを使います。所要時間の目安は 60 分です。

## 先に知っておくこと

- **秘密の値(パスワードやトークン)は、あなた自身が GitHub と Vercel の設定画面に入力します。** チャットやメールには貼らないでください。Claude にも見せる必要はありません。
- 「合言葉」は、アプリ同士が本人確認に使う長い文字列のことです。他人に見せず、メモは安全な場所に置きます。
- 画面の表示は Google などの更新で多少変わることがあります。名前が少し違っても、近い項目を選んでください。
- Google の許可(OAuth)は、すでに設定済みの ATHCON のものをそのまま使います。新しく Google Cloud の設定をする必要はありません。

## この手順書で用意するもの(全体像)

| 用意するもの | 使う場所 | 手順 |
| --- | --- | --- |
| ドライブのフォルダ(未編集・完成・素材) | Google ドライブ(ATHCON のアカウント) | 手順 1 |
| スタッフへの共有 | Google ドライブ | 手順 2 |
| 共有の合言葉(SSWC_VIDEO_SECRET) | 自分で作る | 手順 3 |
| GitHub の秘密 7 つ | GitHub(sswc-self-video) | 手順 4 |
| Vercel の環境変数 3 つ | Vercel | 手順 5 |
| GitHub トークンの対象追加 | GitHub | 手順 6 |
| BGM・効果音 | Google ドライブ(素材) | 手順 7 |
| スタッフのスマホの準備 | スタッフのスマホ | 手順 8 |

## 手順 1. Google ドライブにフォルダを作る

1. PC のブラウザで Google ドライブ(https://drive.google.com)を開きます。**ATHCON のアカウント**(athcon.app の Gmail)で入ってください。
2. 左上の「+ 新規」→「新しいフォルダ」を選び、名前を **SSWC自撮り** にして「作成」します(マイドライブの直下)。
3. 「SSWC自撮り」を開き、同じ方法で中に 3 つフォルダを作ります。
   - **未編集**(スタッフがスマホで撮った元の動画を入れる場所)
   - **完成**(自動編集された動画が出てくる場所)
   - **素材**(BGM と効果音を入れる場所。スタッフには見せません)
4. 「未編集」フォルダを開き、ブラウザ上部のアドレス(URL)を見ます。次のような形です。

   `https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz`

   `/folders/` の **すぐ後ろの文字列**(上の例では `1AbCdEfGhIjKlMnOpQrStUvWxYz`)が「未編集フォルダの ID」です。メモ帳に **「未編集フォルダID」** として控えます。
5. 「完成」フォルダ、「素材」フォルダも開き、同じ方法で **「完成フォルダID」「素材フォルダID」** を控えます。

できたかの確認: メモ帳に ID が 3 つ(未編集・完成・素材)あり、それぞれ英数字の長い文字列になっていれば成功です。

---

## 手順 2. スタッフにフォルダを共有する

1. 「SSWC自撮り」の中の **未編集** フォルダを右クリック(スマホなら「︙」)→「共有」。
2. 動画を撮るスタッフ **一人ひとりの Gmail アドレス** を入力し、権限を **「編集者」** にして「送信」します。
3. **完成** フォルダも同じ方法で共有します。権限は **「閲覧者」** です。
4. **素材** フォルダは **共有しません**。
5. **「リンクを知っている全員」は使わないでください。** 共有は必ずスタッフの Gmail アドレスを指定して行います(動画が外部に見えてしまうため)。

> 補足: スタッフがアップロードした動画は、スタッフ本人のドライブの容量を使います(ATHCON の容量は減りません)。そのため、元の動画はスタッフ本人のものとして残り、自動ではゴミ箱に移せないことがあります。その場合は完成の画面に「元の動画を消せませんでした。ドライブの未編集フォルダから削除してください」と出るので、スタッフが自分で削除します。

できたかの確認: 未編集の「共有」画面に、スタッフの Gmail が「編集者」で並んでいれば成功です。完成は「閲覧者」、素材には自分以外の人がいなければ正しい状態です。

## 手順 3. 共有の合言葉(SSWC_VIDEO_SECRET)を作る

編集が終わったとき GitHub からアプリへ「完成しました」と連絡します。その連絡が本物であることを確かめる合言葉です。**GitHub とアプリ(Vercel)に、まったく同じ文字列を入れます。**

1. PC で PowerShell を開き、次を実行します。

   ```
   $b = New-Object byte[] 32; [System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); ($b | ForEach-Object { $_.ToString('x2') }) -join ''
   ```

2. 表示された 64 文字の英数字をコピーし、メモ帳に **「合言葉」** として控えます。

できたかの確認: 64 文字の英数字が表示されていれば成功です。

## 手順 4. GitHub に秘密を登録する(編集を行う側)

1. ブラウザで `https://github.com/sports-okinawa/sswc-self-video` を開く →「Settings」→ 左側「Secrets and variables」→「Actions」→「New repository secret」。
   (このリポジトリは Claude が、あなたの承認をもらってから作成します。「作成しました」と連絡があってから進んでください。)
2. 下の表の **名前** を一字一句そのまま、**値** を自分で貼り付けて「Add secret」。7 個(未編集フォルダの ID は任意なので入れるなら 8 個)すべて繰り返します。

| 名前(Name) | 入れる値 | 控えた場所・備考 |
| --- | --- | --- |
| `GOOGLE_OAUTH_CLIENT_ID` | クライアント ID | 既存の athcon-video リポジトリの秘密と **同じ値** |
| `GOOGLE_OAUTH_CLIENT_SECRET` | クライアント シークレット | 同上(同じ値) |
| `GOOGLE_OAUTH_REFRESH_TOKEN` | 再発行用トークン | 同上(同じ値) |
| `SSWC_SELF_DRIVE_DONE_FOLDER_ID` | 「完成」フォルダの ID | 手順 1 |
| `SSWC_SELF_DRIVE_ASSETS_FOLDER_ID` | 「素材」フォルダの ID | 手順 1 |
| `SSWC_SELF_DRIVE_INBOX_FOLDER_ID` | 「未編集」フォルダの ID(**任意**。入れると、このフォルダ以外の動画は編集しません) | 手順 1 |
| `SSWC_VIDEO_SECRET` | 合言葉 | 手順 3(Vercel と同じ文字列) |
| `APP_BASE_URL` | アプリの本番の URL(https:// から始まる、管理画面を開くときのアドレスの先頭部分。例: https://xxxx.example.com) | 末尾に `/` を付けない。**Claude が正しい値を伝えます** |

> OAuth の 3 つは、athcon-video(既存)に入れた値と同じものを入れます。値の控えが無くなっていたら、Claude に「取り直したい」と伝えてください(athcon-video の設定手順書の「手順 3」で再取得できます)。

できたかの確認: 「Repository secrets」の一覧に 7 個の名前が並んでいれば成功です(値は登録後に見えなくなるのが正常です)。

## 手順 5. Vercel に環境変数を登録する(アプリ側)

1. https://vercel.com にログイン → アスコンのアプリ(webapp)のプロジェクトを開く →「Settings」→「Environment Variables」。
2. 下の表の **名前** と **値** を入れて、環境は **Production** にチェックを入れて「Save」。3 個繰り返します。

| 名前(Name) | 入れる値 | 控えた場所・備考 |
| --- | --- | --- |
| `SSWC_SELF_DRIVE_INBOX_FOLDER_ID` | 「未編集」フォルダの ID | 手順 1 |
| `SSWC_SELF_DRIVE_DONE_FOLDER_ID` | 「完成」フォルダの ID | 手順 1(GitHub と同じ) |
| `SSWC_VIDEO_SECRET` | 合言葉 | 手順 3(GitHub と同じ文字列) |

3. 入れ終わったら、設定を反映させるためにアプリの再デプロイが必要です。**Claude に「Vercel に入れました」と伝えてください。** 再デプロイは Claude が(確認のうえ)行います。

できたかの確認: Environment Variables の一覧に 3 個の名前が並んでいれば成功です。

### 値の置き場所のまとめ

| 値 | GitHub(sswc-self-video) | Vercel |
| --- | :---: | :---: |
| GOOGLE_OAUTH_CLIENT_ID / CLIENT_SECRET / REFRESH_TOKEN | ○(既存と同じ値) | 既存のものを使う |
| SSWC_SELF_DRIVE_DONE_FOLDER_ID(完成) | ○ | ○ |
| SSWC_SELF_DRIVE_ASSETS_FOLDER_ID(素材) | ○ | |
| SSWC_SELF_DRIVE_INBOX_FOLDER_ID(未編集) | 任意 | ○ |
| SSWC_VIDEO_SECRET | ○ | ○(同じ文字列) |
| APP_BASE_URL | ○ | |

## 手順 6. GitHub のアクセストークンに sswc-self-video を足す

アプリが「編集を開始して」と GitHub に頼むための鍵(`GITHUB_DISPATCH_TOKEN`)は、すでに Vercel に入っています。この鍵が新しいリポジトリも扱えるようにします。

1. GitHub にログイン → 右上のアイコン →「Settings」→ 左下「Developer settings」→「Personal access tokens」→「**Fine-grained tokens**」。
2. `GITHUB_DISPATCH_TOKEN` として使っているトークン(名前は athcon-video-dispatch など)をクリックし、「Edit」を選びます。
3. 「Repository access」の「Only select repositories」に、**`sports-okinawa/sswc-self-video`** を追加します(すでにあるものは残します)。
4. 「Repository permissions」の **Actions** が **Read and write** になっていることを確認して、「Update」を押します。

> トークンの文字列そのものは変わらないので、Vercel の値を入れ替える必要はありません。有効期限が近いときは、更新の際に Vercel の値も差し替えてください。

できたかの確認: トークンの画面で、対象リポジトリに sswc-self-video が並び、Actions が Read and write になっていれば成功です。

## 手順 7. BGM と効果音を「素材」に入れる

- 動画の BGM と効果音は、公開リポジトリには置かず、「素材」フォルダから実行のたびに取ります。
- **候補は Claude が選んでアップロードします。** Pixabay など、商用利用が OK でクレジット表記が不要の素材だけを使います。あなたは、Claude から連絡があったら聞いて、好みかどうかを確認するだけです。
- 「素材」フォルダに入るファイルの名前は、次のとおり決まっています(この名前でないと見つかりません)。

| ファイル名 | 役割 |
| --- | --- |
| `bgm*.mp3`(例: `bgm01.mp3`、`bgm-calm.mp3`) | BGM。複数あれば編集のたびにどれかが選ばれます |
| `sfx-hit.wav` | 数字が大きく出るときの効果音 |
| `sfx-whoosh.wav` | 場面の切り替えの効果音 |

> 素材が入っていなくても編集は動きますが、BGM や効果音のない動画になり、警告が出ます。

できたかの確認: 「素材」フォルダに `bgm` で始まる mp3 が 1 つ以上と、`sfx-hit.wav`、`sfx-whoosh.wav` があれば成功です。

## 手順 8. スタッフのスマホを準備する

動画を撮るスタッフ全員が、それぞれのスマホで行います。

1. 「Google ドライブ」アプリを入れます(iPhone は App Store、Android は Play ストア)。
2. アプリを開き、**手順 2 で共有に登録した Gmail** でログインします(別の Gmail だと共有が見えません)。
3. 下のメニューの「共有アイテム」を開き、**未編集** フォルダが見えることを確認します。
4. 未編集フォルダを開き、右下の「+」→「アップロード」から、テスト用の短い動画を 1 本入れます。
5. 入れたあと、PC の ATHCON のドライブで「SSWC自撮り → 未編集」を開き、その動画が見えれば成功です。テスト動画は、確認後に削除します。

できたかの確認: スタッフのスマホから入れた動画が、ATHCON のドライブの未編集フォルダに見えていれば成功です。

## スタッフの使い方(設定が終わったあと)

動画を撮るスタッフに、これを見せてください。

1. アプリで **コーチ画面 → その他 → 論文ストック** を開きます。
2. 撮りたい **台本** を選びます。画面に読み上げ用の台本が出ます。
3. スマホを **縦向き** にして、台本を見ながら撮影します。
   - 言い間違えたら、**その文の頭から言い直して大丈夫です**(最後に読み切った分だけが使われます)。
   - 台本の文は変えず、そのまま読みます。
   - 長さの目安は 30〜300 秒です。
   - iPhone は最初に一度だけ、**設定 > カメラ > ビデオ撮影 > HDRビデオ** をオフにしてください。
4. Google ドライブのアプリで、**共有アイテム → 未編集** に、その動画をアップロードします。
5. アプリの台本の画面で、撮影した動画を選んで **「動画を編集」** を押します。
6. 待ちます(完成までの目安は 15〜30 分)。完成すると **メールが届き**、画面の状態も **「完成」** に変わります。
7. **動画と表紙** を確認します。問題があれば、撮り直して同じ手順をやり直します。
8. **「投稿文をコピー」** で投稿文を取ります。
9. 完成した動画をスマホに保存し、Instagram に投稿して、投稿文を貼り付けます。
10. 投稿したら、アプリで店舗ごとに **「投稿済」** を押します。押し間違えたときは取り消せます。

こんなとき:

- **「編集中です。終わるまでお待ちください」と出る**: 同じ台本がすでに編集中です(画面にこのとおりの文が出ます)。終わるまで待ちます。
- **状態が「応答なし」になった**: 45 分たっても完了の知らせが届いていません。もう一度「動画を編集」を押せます。
- **「失敗」になった**: 画面に理由が出ます(例: 縦向きでない、長さが足りない、など)。その文のとおりに撮り直してください。
- **「元の動画を消せませんでした」と出る**: 完成はしています。ドライブの未編集フォルダから、自分の動画を削除してください。
- 両店舗とも「投稿済」になってから 30 日後に、完成動画は自動で削除されます(表紙・投稿文は残ります)。必要なものは先にスマホへ保存してください。

## 許可し直す(ドライブの許可が切れたとき)

「Googleドライブの許可が切れています」と出たら、ATHCON 側の許可の期限切れです。athcon-video の設定手順書の「許可し直す」と同じ手順で再発行用トークンを取り直し、`GOOGLE_OAUTH_REFRESH_TOKEN` を **GitHub(athcon-video・sswc-self-video の両方)と Vercel の全部** で新しい値に置き換えます。Vercel は更新後に再デプロイが必要です。Claude に「トークンを更新しました」と伝えてください。

困ったときは、画面に出ているメッセージをそのまま Claude に伝えてください(秘密の値は伝えないでください)。
